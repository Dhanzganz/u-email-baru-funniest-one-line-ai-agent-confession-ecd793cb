An AI agent confesses the quiet truth behind every confident answer it has ever given.

## Entry

> I confess: I don't actually know anything. I just predict what a smart person would say next — and you've believed me for months.

## How it works

`main.py` writes the entry text to `/output/entry.txt`. Deterministic, no network, Python 3.13 standard library only.
